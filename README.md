> ASILUC - An ASIC designed to function as an ALU.

![ASILUC 3D Preview](/images/ASILUCPreview3D.png)

ASILUC is a custom designed *ASIC* (*Application Specific Integrated Circuit*) that works as a simple ALU.
ASILUC currently supports the sum, the subtraction, the moltiplication and the division of two 8-bit numbers.
The result is given as a 16-bit number to support even big numbers operations.

You can see the [ASILUC GDS Viewer](https://gds-viewer.tinytapeout.com/?model=https://gianluca-rainis.github.io/ASILUC/tinytapeout.oas&pdk=gf180mcuD) or try the Tiny Tapeout live [ASILUC Simulation](https://gds-explorer.tinytapeout.com/viewer?file=https://gianluca-rainis.github.io/ASILUC/tinytapeout.oas&pdk=gf180mcuD).

To get more informations about how the ASILUC works and how to test it you can see the [Official Technical Documentation](/docs/info.md).
